# module `classical` (implemented)

Classical invariants: Alexander and Riley polynomials, volumes, torsion polynomials, fields, sector list.

Filled from the knot definition files (src/kdb/knots/*.yaml) and, for generic K_p, from closed formulas in p.

Data path: `data/knots/<knot>/<group>/<side>/classical.json`, validated against `schema.json`.
